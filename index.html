Catatan & Praktik HTML Dasar (Modul 1–15)

Halaman ini dibuat sebagai dokumentasi penyelesaian materi fundamental HTML, mulai dari struktur dokumen dasar hingga penyematan media dan tautan navigasi.

Materi yang Sudah Dipelajari

  • Struktur dasar dokumen HTML (<!DOCTYPE html>, <head>, <body>)
  • Hierarki heading (<h1> sampai <h6>) dan teks paragraf (<p>)
  • Pembuatan daftar terurut (<ol>) dan tidak terurut (<ul>)
  • Penambahan tautan eksternal menggunakan tag <a>
  • Penyematan gambar beserta atribut src, alt, dan ukuran

Langkah Selanjutnya

  1. Melakukan commit dan push file index.html ke repositori GitHub
  2. Memperbarui status progres belajar di halaman Notion
  3. Lanjut mempelajari HTML Semantik, Tabel, dan Formulir
